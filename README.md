# Motor de Base de Datos - Fase 1: Índices B-Tree

## 1. Requisitos de entorno y dependencias
- **Lenguaje:** C++ (Estándar C++17 o superior ).
- **Compilador:** GCC o Clang.
- **Herramientas:** Make o CMake (opcional, para automatizar la compilación).
- **Sistema Operativo:** Compatible con distribuciones Linux, macOS y Windows (vía MinGW o WSL).

## 2. Instrucciones para compilar y ejecutar
Para compilar el proyecto manualmente desde la terminal, ejecute:
```bash
g++ src/main.cpp -o db_engine
